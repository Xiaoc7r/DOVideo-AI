# 代码 Review 与修复记录（2026-09-29）

本轮基于 `origin/main` 的 `498211d`，修复分支为 `codex/debug-ux-review-20260928`。目标是保持既有视频上传、转写、分析、修订、追问和浏览器扩展功能，修复异常与并发边界，并改善失败反馈及键盘操作体验。未引入依赖、数据库结构变更或新的业务功能。

重点检查了 Vue 入口及分析工作区、HTTP/SSE 与分片上传模块，扩展的登录/导入/路由/分析/结果渲染链路，以及后端的上传恢复、任务消费、结果持久化、修订模式、删除清理和 SSE 订阅管理。以下为确认后已落实的修改；这份记录不代表所有外部服务及生产故障组合均已完成验证。

| 优先级 | 触发条件与原行为 | 修复与验证 |
| --- | --- | --- |
| P1 | 分片合并已成功，但客户端没有收到响应；合并后立即删除上传元数据，续传查询会认为任务过期，重新上传并创建记录。 | 保留有 TTL 的归属信息与分片索引，完成回执比元数据多保留 1 小时；迟到的分片请求先检查完成回执。客户端与后端分别回归丢失合并响应后的重试，并检查不会再次上传或创建媒体记录。 |
| P1 | 长时间转写和分析并行运行时，各自将最初查询到的整份媒体实体写回，可能覆盖另一路刚保存的摘要或转写内容。 | 按职责更新摘要、转写字段；分析产生的转写仅在数据库原字段为 NULL 或空串时补写。测试检查传入 Mapper 的字段及条件，保留分析自动保存转写的既有行为。 |
| P1 | 消息消费结束时清理 Redis 活跃标记失败，后续 `unlock` 被跳过，锁可能持续由 watchdog 续期。 | 将锁释放放入独立 `finally`；故障注入验证 Redis 清理抛异常后仍释放持有的锁。 |
| P1 | 已成功的修订消息被再次投递，修订暂存标记已删除，消费者会反复以“状态不存在”失败。 | 暂存不存在时检查相同媒体、目标及模式的已保存结果；已有结果则发布完成事件并返回。回归成功结果不重复调用 AI，缺失结果仍保留失败重试行为。 |
| P1 | 旧请求在退出、重新登录、切换媒体或重新提交之后返回，可能覆盖当前结果、清除新登录，或重新启动旧任务事件流。 | HTTP、列表、上传、工作区及事件流使用会话或操作版本校验；异步读取后再次检查有效性。回归旧 401 不清除新登录、旧历史不覆盖新提交、退出后不重启任务流。切换面板仍保留同一登录下已提交任务的后台跟踪。 |
| P2 | 扩展导入或自动模式路由遇到 401 后，外层失败处理又把登录页切回提交页，路由还可能继续按通用模式提交。 | 认证失效使旧操作版本失效，401 不进入普通模式回退。使用真实侧栏事件处理器配合 DOM/Chrome 模拟对象，分别验证导入和路由失效后保持登录页，且不继续提交分析。 |
| P2 | SSE 已停止但读缓冲区内还有事件，或服务端已发终态但未关闭连接；迟到事件可能写入新界面，读取器长期不释放。 | 网页和扩展在读取后、事件之间检查取消状态；终态及取消时取消并释放 reader。网页流只释放自己的实例，异步回调同时检查取消信号。覆盖缓冲事件、无 EOF 的终态和迟到 HTTP 错误。 |
| P2 | 后端最后一个 SSE 连接移除时，新连接恰好在 `computeIfAbsent` 和 `add` 之间注册，可能加入已从 Map 移除的列表。 | 将注册放入同一键的 `compute` 原子操作，与移除路径保持一致。补充 SSE 终态、重新订阅和模式隔离测试；测试不宣称穷举线程调度。 |

| P2 | 修订请求只在 JSON 中提供 `mode` 时，控制器只读取查询参数，可能将其他模式的修订当成 GENERAL。 | 查询参数为空时采用请求体模式；非空查询参数仍优先。控制器测试覆盖 LEARNING 请求体以及 REVIEW 查询参数覆盖。 |
| P2 | 续传记录未区分用户，同一浏览器换账号容易使用另一个账号的 uploadId；旧版记录直接失效会破坏升级后的续传。 | 新记录按用户隔离，旧记录仅在服务端确认归属后迁移；另一用户的 403 不删除原记录。网络及服务端临时失败保留进度；存储迁移写入失败保留旧凭据；合并阶段取消统一表现为取消。 |
| P2 | 扩展结果展示丢失基础 CSS 类；时间戳处理会改写代码片段，或者把 B 站不同分 P 当成同一视频。 | 保留结果容器基础类；时间戳只在正常行内内容中生成跳转，校验时间格式及安全整数；视频匹配区分分 P 与大小写敏感标识；使用本次提交的视频地址判断跳转目标。 |
| P2 | 浏览器声称 MIME 为视频时，网页允许选择后端不支持的后缀；扩展校验通过的标准化地址与实际提交值不一致。 | 网页文件选择与校验统一使用后端已有后缀范围；扩展提交已标准化的 HTTP(S) 地址，并沿用 500 字目标限制。测试覆盖 MIME 绕过、地址标准化和无效时间。 |
